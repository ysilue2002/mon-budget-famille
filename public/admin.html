Réglages

Une seule configuration pour toute l'application.

Lien officiel

L'adresse que vous partagez : elle sert aux e-mails, aux liens de facture et aux QR. Une seule adresse, partout.

E-mails de réinitialisation

Le commerçant demande un code depuis « Mot de passe oublié ? » et le reçoit par e-mail. Sans e-mail configuré, vous donnez le code par WhatsApp depuis l'onglet Boutiques.

Paiement du Premium

Le commerçant choisit un nombre de mois, paie par Wave, Orange Money ou carte, puis vous validez le transfert dans l'onglet Paiements. Prix vide (0) : seul le code d'activation reste.

À 0 : un administrateur suffit. Au-delà, un premier donne son accord et un autre doit le confirmer.

Chaque personne son code

Ajoutez le secret ADMIN_CODES au format email:code,email:code (Sites → Secrets), puis redéployez. Chacun entre avec son propre code et le journal note qui a agi. Sans ce secret, le code commun ADMIN_CODE continue de marcher.

Second facteur : secret ADMIN_TOTP au format email:BASE32 (une application d'authentification). Le code à 6 chiffres est alors demandé avec le code d'administration.

Codes de secours

Téléphone perdu ? Un code de secours remplace les six chiffres, une seule fois. Créez-en huit et gardez-les ailleurs que sur le téléphone.

Support WhatsApp

Le bouton « Support WhatsApp » des comptes Premium et la demande de code y arrivent. Laissez vide pour le masquer.

Avec les deux renseignés, l'application propose WhatsApp. Avec l'e-mail seul, elle ouvre un message prérempli. Avec aucun, les boutons d'assistance restent masqués.
